Incominator: build the APK on your phone

1. Make a free account at github.com and create a new repository (any name).
2. Upload everything from this folder to it. On a phone, use "Add file" then "Upload files".
   Make sure the hidden .github folder goes up too.
3. Open the Actions tab. The build starts by itself (about 5 minutes). If not, open "Build APK" and tap Run workflow.
4. When it turns green, open the run and download "Incominator-apk" at the bottom. Unzip it.
5. Open app-debug.apk on your phone and allow installs from this source when Android asks.

Back up your data from Settings inside the app before reinstalling or updating.
